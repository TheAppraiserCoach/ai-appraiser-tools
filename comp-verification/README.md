# Comp Verification

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/comp-verification/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Drafts one verification email per listing agent, asking about concessions, buyer-agent compensation, multiple offers, and close price and date.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Paste or attach your comps (address plus agent name and email) and add your signature info. Send.
5. Read each email once, then send it from your own inbox.
