UAD 3.6 to SFREP: MISMO Generator

Turn a UAD 3.6 appraisal built in Claude into a MISMO 3.6 XML file that Appraise-It Pro can import and UCDP can accept. Free, open-source code.

← All tools

1What this is

Fannie Mae and Freddie Mac do not accept a report from Claude. They accept a UAD 3.6 file in MISMO 3.6 XML format. This tool is the bridge: Claude fills in the appraisal data, the generator writes the XML in the exact order the official schema requires, and then it checks the file before you ever upload it.

Appraise-It Pro (SFREP) can import MISMO 3.6 directly, so the finished file opens as an editable report. You add photos, review, sign, and deliver as usual.

2What it checks before you upload

Schema check. Validates against the official GSE UAD 3.6 schema.
Link check. Every relationship must point at something that exists.
Element order. Taken from the schema, so nobody has to remember it.
Data dictionary. All 4,066 fields with definitions and allowed values, for Claude to read.

The link check catches the UCDP fatal error "The 'from' label included in a RELATIONSHIP container is missing." That error happens when a source or date field is blank and the software drops the item but leaves the link behind.

3How to use it

  1. Get the code. Download this folder from GitHub. You need Python and one install: pip install -r requirements.txt.
  2. Download the official files. Run ./scripts/fetch_gse.sh. It pulls the schema and 14 sample reports straight from Freddie Mac.
  3. Start from a sample. python3 -m uad36mismo to-json samples/SF1_Appraisal_v1.4.xml -o report.json
  4. Let Claude fill it in. Give Claude report.json, the data dictionary, and your assignment data. Ask it to replace the sample values and keep every label paired with its relationship.
  5. Build and check. python3 -m uad36mismo build report.json -o report.xml. If it reports problems, paste them back to Claude and repeat.
  6. Import. In Appraise-It Pro: File, Import, MISMO. Review, add photos, sign.

4Honest status

Proven: all 14 official Fannie Mae and Freddie Mac sample reports (single family, condo, co-op, manufactured home, 2-4 unit, completion reports) convert to the tool's format and back with no data change, and pass schema validation.

Not yet proven: a file generated by this tool has not yet been imported into Appraise-It Pro or submitted to UCDP. Test on a throwaway file first and tell us what you find. Photo handling is not built yet; SFREP documents optional MISMO 3.6 image extensions for that.

This is a tool, not a substitute for your review. You sign the report.
