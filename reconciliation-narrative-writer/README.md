# Reconciliation Narrative Writer

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/reconciliation-narrative-writer/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Reads your adjusted grid, suggests weights across your closed sales, and drafts the reconciliation narrative.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Attach the report PDF or a screenshot of the grid. Send.
5. Check the comp statuses and weights, then paste into TOTAL.

Needs a paid AI plan with a model that can see images.
