# Engagement Letter Parser

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/engagement-letter-parser/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Pulls every order-setup field out of an engagement letter (address, borrower, lender, AMC, fee, due date, contacts, case numbers) so you can stop retyping.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Attach the engagement letter PDF and send.
5. Copy the fields into TOTAL's assignment tab.
