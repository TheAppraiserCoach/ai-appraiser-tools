# Photo Quality Checker

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/photo-quality-checker/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Reviews every photo in your report and flags missing angles, missing interior shots, and condition or quality ratings the photos don't support.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Attach your completed report PDF (photos must show in the PDF) and send.
5. Give it 1 to 2 minutes. Fix the CRITICAL and MATERIAL items.

Needs a paid AI plan with a model that can see images.
