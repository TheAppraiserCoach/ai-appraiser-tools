# Neighborhood Narrative Builder

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/neighborhood-narrative-builder/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Give it the subject address and your four trend boxes. You get suggested N/S/E/W boundaries plus the Neighborhood Description and Market Conditions narratives.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Under the prompt, type the subject address and your trend-box selections. Send.
5. Check the boundaries on a map, fill any [PLACEHOLDER], paste into TOTAL.
