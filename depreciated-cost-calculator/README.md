# Depreciated Cost Calculator

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/depreciated-cost-calculator/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Drop in an appraisal PDF and get supported adjustment ranges for GLA, basement, and garage based on the report's own cost approach. This one runs right on the page. No AI account needed.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Drag your appraisal PDF onto the page.
3. Check the numbers it pulled in, add your comps, and click **Compute adjustments**.
4. Copy the suggested narrative and edit it before it goes in your report.
