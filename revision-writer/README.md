# Revision Response Writer

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/revision-writer/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Turns an AMC or underwriter revision request into addendum-ready responses in your voice, including USPAP-grounded pushback when a request isn't supportable.

**How to use it**

1. Click **OPEN THIS TOOL** above.
2. Click **📋 Copy prompt**.
3. Open [Claude.ai](https://claude.ai) or [ChatGPT](https://chatgpt.com), start a new chat, and paste.
4. Attach the report PDF **and** the revision request (or paste the request under the prompt). Send.
5. Fill any [PLACEHOLDER] notes, then paste into your addendum.
