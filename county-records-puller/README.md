# County Records Puller

## 👉 [OPEN THIS TOOL](https://theappraisercoach.github.io/ai-appraiser-tools/county-records-puller/)

**Click the link above to use it.** The file you see in this folder (`index.html`) is the raw code behind the page. You don't need to open or download it.

Give it a subject address. Claude opens your county's own websites in your browser and pulls the assessor record, tax card, GIS map, plat, legal description, and ownership history into one subject data sheet, with a source link for every figure.

**How to use it**

1. One time: install the **[Claude in Chrome](https://claude.com/claude-in-chrome)** extension and sign in. This tool runs inside your Chrome browser, not in a regular chat.
2. Click **OPEN THIS TOOL** above, then click **📋 Copy prompt**.
3. Open the Claude side panel in Chrome, paste the prompt, and add the subject address (plus the parcel number if you have it). Send.
4. If it stops at a CAPTCHA or login, handle it yourself and tell Claude "continue."
5. Review the data sheet and save the county cheat sheet it gives you for next time.

It only reads public records. It never buys documents, submits forms, or asks for your passwords. Needs a paid Claude plan.
